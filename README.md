# 📋 Gestion des Utilisateurs — Spring Boot CRUD

Une application web pédagogique de gestion des utilisateurs développée avec **Spring Boot**, **Thymeleaf** et **Spring Data JPA**, couvrant l'ensemble des opérations **CRUD** (Créer, Lire, Mettre à jour, Supprimer).

---

## 🚀 Fonctionnalités

- Afficher la liste de tous les utilisateurs
- Ajouter un nouvel utilisateur
- Modifier les informations d'un utilisateur existant
- Supprimer un utilisateur
- Stockage des données dans une base **MySQL**

---

## 🛠️ Technologies utilisées

| Couche       | Technologie              |
|--------------|--------------------------|
| Backend      | Java 21, Spring Boot 3.5.12 |
| Vue (Front)  | Thymeleaf, HTML/CSS      |
| Persistance  | Spring Data JPA, Hibernate |
| Base de données | MySQL                 |
| Build        | Maven                    |

## 🔗 Endpoints

| Méthode | URL                   | Description                     |
|---------|-----------------------|---------------------------------|
| GET     | `/users`              | Liste de tous les utilisateurs  |
| GET     | `/users/new`          | Formulaire d'ajout              |
| POST    | `/users/save`         | Enregistrer un utilisateur      |
| GET     | `/users/edit/{id}`    | Formulaire de modification      |
| POST    | `/users/update/{id}`  | Mettre à jour un utilisateur    |
| GET     | `/users/delete/{id}`  | Supprimer un utilisateur        |


---

## 🎯 Objectif pédagogique

Ce projet a pour but d'illustrer de manière simple et concrète :

- L'intégration de **Spring Boot** avec **Thymeleaf**
- La mise en place d'un **CRUD complet** dans une application web Java
- L'utilisation de **Spring Data JPA** pour l'accès aux données
- L'architecture **MVC** appliquée à un projet Java moderne
